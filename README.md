# RetailOne POS

Hệ thống POS web cho cửa hàng bán lẻ vừa và nhỏ.

## Cài đặt & Chạy
1. Chạy `Database/RetailOne_DB_Schema.sql` trên SQL Server.
2. Backend:
   ```bash
   cd backend
   npm install
   npm run seed
   npm run dev
   ```
3. Frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
