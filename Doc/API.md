# Hợp đồng API (API Contracts)

Cập nhật danh sách endpoint khi hoàn thiện các Phase.

## 1. Authentication
- `POST /api/auth/login`: Đăng nhập (UC69)
- `GET /api/auth/me`: Lấy thông tin phiên hiện tại

## 2. Products & Categories
- `GET /api/products`: Danh sách sản phẩm (UC48)
- `GET /api/categories/options`: Lựa chọn danh mục cho bộ lọc
